# Pranav Kumar Veligatla — Portfolio

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or installation are required.

## Personalise before publishing
- Replace the `PK` initials/photo placeholder in `index.html` with your own image.
- Verify your LinkedIn URL; the supplied URL may need your actual public profile URL.
- Add real certifications and achievements when you have them.
- Add a resume PDF and link it from the hero or contact section when ready.
- Update project details and GitHub repository URL when the project repository is public.

## Files
- `index.html` — content and page structure
- `style.css` — responsive dark-premium design
- `script.js` — mobile navigation and reveal animations
